# home-automation
Home automation projects

The current home automation server consists of the following components

## Hardware

- Raspberry Pi 4 Model B Rev 1.4 - 8GB RAM
- Crucial MX500 250GB SATA 2.5 Inch SSD 
- SATA to USB 3.0 adapter
- Aluminum heatsink case for Raspberry Pi 4 - Obsidian Black

## Software

- OS: Debian GNU/Linux 13 (trixie) aarch64
- Kernel: Linux 6.18.50+rpt-rpi-v8
- Docker: 29.8.1 rootless
- Home Assistant: 2026.3.4
- Eclipse Mosquitto: 2.1.2-alpine
- Caddy: 2.11.4
